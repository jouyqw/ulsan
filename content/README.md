# 칼럼 자동화 사용법

## 1. 기본 구조

칼럼 원고는 `content/columns`에 저장합니다.

빌드를 실행하면 아래 항목이 자동으로 바뀝니다.

- 칼럼 상세페이지 생성
- 칼럼 목록 추가
- 메인 최신 칼럼 반영
- 사이트맵 추가
- SEO 기본 메타 태그 생성

## 2. 사건별 제목 앞 키워드

`scripts/create-column.js`를 쓰면 사건 유형에 맞춰 제목 맨 앞에 키워드가 자동으로 붙습니다.

| 유형 | 붙는 키워드 |
| --- | --- |
| `general` | 울산변호사 |
| `criminal` | 울산형사변호사 |
| `criminal-specialist` | 울산형사전문변호사 |
| `sex` | 울산성범죄변호사 |
| `divorce` | 울산이혼변호사 |
| `civil` | 울산민사소송변호사 |
| `traffic` | 울산교통사고변호사 |
| `drunk` | 울산음주운전변호사 |
| `drug` | 울산마약변호사 |

## 3. 새 칼럼 생성 예시

```powershell
npm run new:column -- --type criminal-specialist --title "집행유예 중 무면허 사고 벌금형 성공사례" --body draft.txt --image proof.png --result "벌금 1,000만 원"
npm run build
git add .
git commit -m "Add new column"
git push
```

## 4. 추천 작업 방식

가장 쉬운 방식은 아래 3가지만 준비하는 것입니다.

1. 칼럼 원고 텍스트
2. 판결문 또는 결정서 이미지
3. 사건 유형

그 다음 Codex가 제목, 표, 문단, SEO 설명, 이미지 배치, 배포까지 처리합니다.

## 5. 예약 발행

frontmatter의 `date`가 **미래 날짜면 그날이 될 때까지 빌드에서 제외**됩니다.

원고를 미리 여러 편 커밋해두면 정해진 날짜에 하나씩 공개됩니다.

```
date: "2026-08-07"   ← 8월 7일 09:00(KST)에 자동 공개
```

`.github/workflows/publish-columns.yml`이 매일 09:00 KST에 빌드를 돌리고,
발행할 글이 있을 때만 커밋합니다. 커밋이 푸시되면 Cloudflare Pages가 배포합니다.

예약분까지 미리 확인하려면 아래처럼 실행합니다. **이 결과는 커밋하지 마세요.**

```powershell
$env:PUBLISH_ALL="1"; npm run build    # 전부 빌드해서 확인
Remove-Item Env:\PUBLISH_ALL; npm run build   # 원래대로 되돌리기
```

되돌리는 빌드에서 아직 발행일이 안 된 글의 HTML은 자동으로 삭제되므로,
실수로 미리 빌드했더라도 다시 빌드하면 정리됩니다.

## 6. 분야 분류

`category` 값에 포함된 단어로 분야가 자동 결정되고, 분야별 칼럼 페이지
(`/columns/<분야>/`)와 상담 페이지 링크가 자동으로 연결됩니다.

| category에 넣는 말 | 분야 | 연결되는 상담 페이지 |
| --- | --- | --- |
| 형사 | 형사 | `/criminal/` |
| 성범죄, 추행, 강간, 성폭력 | 성범죄 | `/sex-crime/` |
| 마약 | 마약 | `/criminal/` |
| 음주 | 음주운전 | `/dui/` |
| 사기 | 사기 | `/criminal/` |
| 상간, 부정행위 | 상간소송 | `/affair-lawsuit/` |
| 이혼, 재산분할, 양육권, 위자료, 혼인 | 이혼 | `/divorce/` |
| 민사, 임대차, 부동산, 보증금, 대여금 | 민사·임대차 | `/civil/` |

위 단어가 하나도 없으면 `기타`로 분류되어 분야 페이지와 링크가 붙지 않습니다.
새 칼럼을 쓸 때 `category`를 먼저 확인하세요.

## 7. 본문에서 쓸 수 있는 블록

| 문법 | 결과 |
| --- | --- |
| `:::summary` | 핵심 요약 박스 |
| `:::table` | 2열 표 (`제목 \| 내용` 형식으로 한 줄씩) |
| `:::quote` | 상담 대화 인용 박스 |
| `:::crisis` | 주의·위험 상황 박스 |
| `:::strategy` | 해결 전략 박스 |
| `:::verdict` | 결과 박스 |
| `:::cta` | 상담 안내 박스 |
| `==문장==` | 강조 밑줄 |

`:::table`의 첫 줄을 `질문 | 답변`으로 시작하면 그 표가 **FAQPage 구조화
데이터로 자동 변환**되어 구글 검색 결과와 AI 답변에 인용될 확률이 올라갑니다.
새 칼럼에는 되도록 Q&A 표를 하나 넣으세요.

관련 칼럼 목록과 분야 상담 링크는 자동 생성되므로 본문에 직접 쓰지 않아도 됩니다.
